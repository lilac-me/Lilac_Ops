# 本文件是「每个模型独立固化 md」的结构模板 / 范本

> **用途**：finalize 阶段为每个具体模型/场景创建独立 md 文件，复制本模板并填充。
> **命名规则**：`模型-机型-输入x输出.md`（模型名在前、机型在后，场景用「输入x输出」表示），
> 例如 `DeepSeek-V3.1-671B-950DT-2Kx20K.md`、`Qwen3-235B-A22B-910C-4Kx32K.md`。
> 每个成功寻优（或产出已验证结论）的「模型 + 机型 + 输入输出场景」组合对应一个文件；
> 同一模型不同场景（不同输入/输出长度）可拆成多个文件，文件名用场景区分。
>
> 文件放置目录：`plugins/inference-model-optimize/knowledge/models/`。
> 每个文件只收录实测数据（吞吐/TTFT/TPOT + 配置），不写未验证推测。

## ① 模型与场景档案

| 项 | 值 |
| ---- | ---- |
| 模型名 | e.g. DeepSeek-V3.1-671B |

## ② 最优配置结论

- **最优拓扑**：TP×DP×EP（如 TP8 / DP1 / EP8）；EP 是否开启、DCP 是否开启及配的档位
- **最优并发 / 饱和点**：e.g. c128-160，饱和点 128
- **关键参数**：gmu、调度器、KVCacheOffload、编译等本场景起到决定性作用的参数
- **一句话结论**：本场景最有效的优化手段是什么
