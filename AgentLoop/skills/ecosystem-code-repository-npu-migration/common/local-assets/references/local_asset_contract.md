# 本地资产清单契约

`.npu-agent/local_asset_inventory.json` 使用 `schema_version=local-asset-inventory-v1`，记录精确的授权模型/数据集根目录、发现的叶节点、完整性证据、限制、错误和稳定的清单摘要。

这个 JSON 文件是唯一的持久化资产清单。模型和数据集记录应保存在其中的 `models` 和 `datasets` 数组中；不要创建 Python 集合或 entry-to-asset 绑定文件作为另一个事实来源。

只有所有被引用 shard 都存在且非空时，模型索引证据才有效。只有被引用的文件或 split 存在且非空时，数据集元数据才有效。元数据本身不是完整性证据。

配置的根目录变化时重新构建。最大深度、目录数或资产数任一发生截断，都会使清单不完整；不要把未访问的路径报告为不存在。

通过精确的规范化别名、已明确审查的绝对索引路径或唯一叶节点别名解析资产。多个匹配时返回 `AMBIGUOUS`，不要从相似名称推断任务兼容性。

调用方必须证明真实命令消费了选定路径。缺少资产只阻塞需要它的 workload，绝不授权自动下载。
