# 四维典型判例（cases）

> 判例仅作语义判定参考；最终等级由"类型等级（rules.yaml severity）取高 + 投票"决定。

## 正确性

| 样例 | 问题 | 规则 | 等级参考 |
| ------ | ------ | ------ | --------- |
| 文档声称"支持 8 卡并行"但代码仅支持 1/2/4 卡 | 限制条件与实际不一致 | R-COR-007 | critical |
| 特性说明写"默认开启"但实现默认关闭 | 开关语义错误 | R-COR-007 | critical |
| 性能数据未标注硬件/版本/复现条件 | 指标口径缺失 | R-COR-008 | major |
| 环境变量含义描述与代码注释冲突 | 注释过时或误导 | R-COR-005 | major |
| 示例命令路径在仓库中不存在 | 代码示例不可运行 | R-COR-002 | critical |
| 参数名拼写与代码定义不一致 | 参数说明错误 | R-COR-003 | critical |
| 参数默认值与代码不一致 | 参数说明错误 | R-COR-003 | major |
| 版本号与配套表不一致 | 版本信息错误 | R-COR-004 | critical |
| 链接 404 或指向错误分支 | 失效链接 | R-COR-001 | critical |
| 跨仓链接指向 master 而非版本分支 | 分支错误 | R-COR-004 | major |
| 截图内容与当前版本界面不符 | 截图过时 | R-COR-006 | major |

## 完整性

| 样例 | 问题 | 规则 |
| ------ | ------ | ------ |
| 仓库缺"安装指导"资料（文件与标题均未匹配） | 必备资料缺失 | R-COM-001 |
| 无硬件/软件前置说明 | 前置条件缺失 | R-COM-002 |
| 操作无结果判定 | 成功标志不明确 | R-COM-003 |
| 正文插图占位未登记 figure_requests.json | 插图诉求缺失 | R-COM-008 |
| 残留 `<...>` 未给出实际值 | 占位符未填 | R-COM-006 |

## 易理解

| 样例 | 问题 | 规则 |
| ------ | ------ | ------ |
| 术语首次出现未解释 | 术语未定义 | R-CLA-002 |
| 单段 8 句且无标题 | 段落过长 | R-CLA-003 |
| "应该可以运行" | 不确定表述 | R-CLA-001 |
| "设置后速度变快" | 无量化结果 | R-CLA-004 |
| 中英混杂段落 | 语言不统一 | R-CLA-008 |
| 步骤顺序与因果颠倒 | 逻辑不连贯 | R-CLA-001 |

## 易获取

| 样例 | 问题 | 规则 |
| ------ | ------ | ------ |
| 安装指南不在 README 中 | README 无导航入口 | R-ACC-001 |
| 需 6 次点击到达 FAQ | 跳转超过 5 步 | R-ACC-003 |
| README 列出已删除文档 | 入口与目录不一致 | R-ACC-006 |
| 全篇无关键词标题 | 标题不可检索 | R-ACC-004 |
| 新文档未登记 README 入口 | 登记缺失 | R-ACC-006 |

## 检查方法

- 语义类：对照目标仓代码实现与 PR/Issue 记录。
- 代码类：复制命令到目标仓实测；参数对照代码定义。
- 链接类：依赖 lint link 子模块客观结果，跨仓链接复核分支与目标仓。
